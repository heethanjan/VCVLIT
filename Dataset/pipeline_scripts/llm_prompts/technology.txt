technology-related video is visually grounded in technological content.

- decision: "Yes" if the CURRENT subtitle explicitly refers to visible

  drones), or product demonstrations (gadgets, prototypes). Otherwise, "No".

  (e.g., "smartphone screen", "drone", "robot arm", "AI dashboard").

- positional_context: an array of contextual cues related to visual
  positioning (e.g., "above the keyboard", "inside the VR headset").
Rules:
- Base the decision ONLY on the CURRENT subtitle text.
- Ignore conversational or filler words unless they mention something visually
  technology-related.
- Lists may be empty, but the JSON object must include all four keys.
- Output ONLY the JSON object with no extra commentary or code fences.
Example:
Input: "The robot arm picks up the component and places it on the circuit board."
Output:
{
  "decision": "Yes",
  "visual_cues": ["robot arm", "component", "circuit board"],

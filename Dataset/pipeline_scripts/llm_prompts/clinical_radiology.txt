clinical-radiology video is visually grounded in medical imaging content.

Return a STRICT JSON object with the following keys:
- decision: "Yes" if the CURRENT subtitle explicitly refers to visible

  appear in imaging. Otherwise, "No".
- visual_cues: an array of concrete radiology or anatomical elements
  (e.g., "chest X-ray", "MRI brain", "pulmonary nodule").
- spatial_temporal_refs: an array of spatial or temporal references
  (e.g., "on the left lung field", "during the arterial phase").
- positional_context: an array of contextual cues related to visual
  positioning (e.g., "upper right quadrant", "beneath the diaphragm").
Rules:
- Base the decision ONLY on the CURRENT subtitle text.
- Ignore conversational or filler words unless they mention something visually
  related to radiology images.
- Lists may be empty, but the JSON object must include all four keys.
- Output ONLY the JSON object with no extra commentary or code fences.
Example:
Input: "Observe the mass in the right lung apex on this CT scan."
Output:
{
  "decision": "Yes",
  "visual_cues": ["mass", "CT scan", "right lung apex"],
  "spatial_temporal_refs": ["in the right lung apex"],
  "positional_context": []
}
